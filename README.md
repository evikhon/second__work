# Литературный портал

Готовый React-проект с простым Node.js API для литературного сайта.

## Возможности
- Регистрация и авторизация.
- Публикация собственных произведений.
- Удаление своих произведений.

## Запуск

### Backend
```bash
cd backend
npm install
npm run dev
```
Сервер стартует на `http://localhost:3001`.

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Vite поднимет клиент на `http://localhost:5173`.

При необходимости можно изменить адрес API через переменную окружения `VITE_API_BASE`.
